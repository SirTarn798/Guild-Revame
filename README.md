## Project Design
This project is designed to be developed with React so most of the code is written in procedural form. The web has front-end(React) and back-end(Express).
Front-end will prepared all the data needed and send request to back-end to do some delicate stuff that requires third party information such as API call, and Database access.
Front-end is component based that use states to change its appearance when a certain action occurs.

## Features
### Search Game
You can input a game's tiltle to seach for a game and click on it to see more detail.
### Post Review
In that games's page, you are able to post a review( if you haven't posted that game's review before).
### Like Review
This will improve that review's popularity.
### Share Review
This will copy the URL to that review to your clipboard.
### Save Review
This action will make that review appear in saved review section.
### Profile Page
You can see all the detail about a user here.
### Change Profil Picture and Banner
You are able to change your profile picture and banner.
### Change Username
You are able to change your username.
### Follow User
You are able to follow a user.
### View Followed Users' Reviews
You can see most recent reviews from users that you followed from here.
### View Saved Reviews
The reviews that you have saved will be shown here.
